# 知行 Life Agent：产品方向与创意赛表述

定位：懂进展、会调整的个人成长助手。把零散想法变成行动，把行动结果变成下一步计划。主线是卡点救援与计划自适应，手机是日常入口，科研实验是特色场景。

演示故事：口述目标 → 形成计划 → 执行遇阻 → 带背景提醒 → 点击我卡住了 → 澄清困难 → 最小行动建议 → 用户确认 → 记录结果与调整原因。

已实现原型：本地数据库保存、语音转文字入口、事项/路线/实验范围选择、变更预览与确认、决策记录、事实与假设分栏、卡点引导、页面内定时提醒及稍后提醒。提醒不自动修改任务。关闭页面不推送；休眠后回到页面检查逾期提醒。

尚待验证：真实模型的建议质量、是否尊重时间预算、是否引用已有依据。测试中的模型替身不等于真实智能效果。

拟实现：手机独立本地数据库、系统后台通知、跨事项计划调整及时间预算校验、电脑手机同步。当前是手机响应式网页，不是已完成的手机应用；本机127.0.0.1服务也不能直接让手机远程访问。

申报材料明确区分已实现、原型和拟实现，不把规划写成验证过的成果。暂不堆叠多Agent、知识图谱和云账号。先验证最小行动是否真正帮助用户推进目标。
