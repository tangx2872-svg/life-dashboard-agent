# 90秒Demo与答辩
0–15秒：展示Today，说“明天下午安排45分钟六级听力”。等待时解释使用已有上下文，不填复杂表格。
15–35秒：逐条预览，明确尚未写入。若清单缺失，先修复再录制，不剪接成假成功。
35–55秒：“改到后天，轻松一点”，展示同一提案修订。
55–75秒：确认，进任务列表刷新证明持久化。
75–90秒：当前会话撤销，回到原状态。不要刷新后再承诺Undo还在。
备选：短录屏备份需标明录制日期和版本。外部AI慢时明确等待，不用固定回复冒充。
## 常见答辩
为什么是Agent？读取授权上下文、生成受控动作、确认执行和反馈循环；不是仅返回建议文本。
与通用聊天区别？提案落到真实任务，支持归属/版本校验和持续调整；无未经对照实验的优越性承诺。
多Agent吗？目前是职责模块和规则/模型混合流程，不冒充多个独立自主智能体。
模型自研吗？不是，使用第三方模型；贡献在交互、上下文组织与受控执行。
能保证计划合理吗？不能；通过约束、预览、用户确认和评测减少错误。
数据在哪里？按部署形态存在本地或服务器MySQL，必要上下文会发第三方。
响应多久？历史报告有秒级到近一分钟波动，偶发超时；不能承诺固定秒数。
华为云技术在哪里？当前证据不足；若规则要求必须使用，应先真实接入验收再申报，不能改架构图冒充。
