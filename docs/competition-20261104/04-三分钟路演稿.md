# 三分钟路演稿
大家好，我们是知行Life Agent团队。我们想解决的，是很多人有想法，却不知道下一步怎么开始。
比如准备考试、推进论文，或者周末出去走走。待办工具通常要求用户先拆好任务；聊天助手虽然能建议，建议却容易留在对话里。知行把这两步连起来。
用户直接说一句话。信息已经够，就给出安排；信息不够，只追问影响决策的条件。一次散步不需要一整年计划，一项长期目标也不该只得到一句加油。
系统结合当前项目、已有任务和用户允许使用的偏好，提出一份能修改的计划。用户可以说轻松一点、换个时间，继续在原方案上调整。预览后确认，才保存到任务列表；取消不会改变原数据。
这里的Agent不是模型直接操作数据库。模型给结构化建议，程序检查账户归属、数据版本和允许的动作，确认后执行。做过的事情可以回顾，反馈帮助下一次安排。
我们已经实现项目任务管理、账户隔离和持久化，并在此前服务器验收中验证真实模型追问、计划确认和撤销，以及音频文件转写。当前已补充逐条预览与请求容错，仍需持续改善上游响应波动和刷新后的撤销体验；浏览器麦克风与公网可信证书需要单独验收。
接下来的演示，用一条明确任务和一次改计划，展示从一句话到保存结果的完整过程。我们关注的不是生成更多文字，而是让用户看清下一步，并始终保留决定权。谢谢大家。
注：现场按实测替换验证句；没有录屏或日志的能力不要声称已验收。讲速按实排调整，正式时长以比赛规则为准。
