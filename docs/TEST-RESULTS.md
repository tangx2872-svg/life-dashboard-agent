## 测试边界

不是多用户压力测试，没有联网模型、真实语音识别、线上部署测试。没有导入个人真实备份；需要用户自行从旧站下载完整备份后在本地版预览恢复。测试验证了新连接和新浏览器读取持久数据，没有模拟磁盘损坏或断电。

## 如何复跑

1. `npm install` 或 `pnpm install --frozen-lockfile`。
2. `node scripts/local-mysql.mjs`，确保项目自己的独立 MySQL 已启动。
3. `npm test` 运行数据库测试。
4. 浏览器测试需安装 Playwright，并把 `BROWSER_MODULE` 设为其 `index.mjs` 的绝对路径；必要时设置 `CHROME_PATH`。然后再次运行 `npm test`。

测试只创建和清理带随机后缀的 `life_dashboard_test_*` 数据库；不会清空 `life_dashboard`。
