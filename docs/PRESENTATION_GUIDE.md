# PPT / 项目文档材料指南

> 面向不写代码或只做演示的同学。所有内容基于当前已实现的功能，不虚构未上线能力。

## 一句话介绍

**知行 Life Agent：说一句话，AI 帮你把模糊想法变成可确认、可执行、可撤销的安排。**

## 核心痛点

1. 传统待办工具要求用户先想清楚目标、再逐条拆分填写，门槛高。
2. 聊天式 AI 能给建议，但建议停在对话里，和真实任务进度脱节。
3. 计划工具一旦生成就难以调整，用户不敢用。

## 解决方案

- 用户只说一句自然语言（可语音），系统负责理解、追问、拆解。
- AI 产出的只是**提案**，用户点「确认安排」后才写入任务/项目。
- 同一轮规划只保留一张**当前方案卡**，修改后原地更新，页面不堆叠历史版本。
- 确认后生成 `changeBatchId`，可一键整批撤销。

## 系统流程

```
一句想法 / 语音
   ↓ ASR（Gemini）
文本 + 页面上下文
   ↓ Node 主站 (/api/planner/turn)
   ↓ Python AI (/api/life/propose)
分层路由：FAST（普通） / PLANNER（复杂）
   ↓ 模型返回结构化 proposal
方案卡：标题 / 时间 / 任务 / 冲突提醒 / 可调整建议
   ↓ 用户确认 (/api/life/confirm)
MySQL 写入 + 可撤销批次
```

## 技术架构

| 层 | 技术 |
| --- | --- |
| 前端 | 原生 HTML/CSS/JS，无框架、无打包 |
| 主站 | Node.js 24 + MySQL 8（`dashboard_state` 文档式存储 + revision 冲突控制） |
| AI 服务 | Python 3.10 + FastAPI + Pydantic |
| 模型 | AutoDL OpenAI-compatible：DeepSeek-V4.1-Flash / gpt-5.6-luna / GLM-5.3-Flash |
| 语音 | Gemini 3.5 Flash（ASR） |
| 部署 | Nginx（HTTPS）→ Node :3000 → Python :6016，systemd 托管 |

## 核心创新

1. **提案—确认分离**：AI 不直接改数据，用户始终拥有最终决定权，可撤销。
2. **分层模型路由 + 有序降级**：普通请求走 FAST（DeepSeek），异常自动切 Luna，再切 GLM，用户无需重输。
3. **滑动窗口熔断**：连续失败进入冷却，冷却模型降到最后仍可兜底。
4. **单卡原地更新的方案展示**：同一轮规划只保留最新方案 + 一行「已调整」，避免多版本堆叠。
5. **长期记忆与快照**：`agent_memory` 保存稳定偏好，设置页可查看「Life 对你的理解」。
6. **全链路语音**：录音 → 转写 → 结构化 → 确认，失败可重试且不丢内容。

## Demo 操作流程（建议 3～5 分钟）

1. 打开 https://122.51.80.161 （自签名证书，点「高级 → 继续访问」）。
2. 用访客入口或注册新账号进入首页。
3. 输入：「周末想去嘉兴玩」→ 展示 AI 追问（玩几天 / 偏好）。
4. 选择「1 天」→ 生成方案卡：标题、日期、任务、冲突提醒、可调整 chips。
5. 点「继续调整」→ 输入「预算控制在 500 以内」→ **同一张卡原地更新**，顶部出现「已调整：…」。
6. 点「确认安排」→ 任务进入列表；再点「撤销这次安排」演示可逆。
7. 打开设置 →「我的轨迹 / Life 对你的理解」，展示记忆摘要。
8. 可选：访问 `/api/life/router/status` 展示模型健康与降级链。

## 可展示的数据

模型基准（`benchmarks/fast-model/results/2026-10-30/summary.json`，30 次真实调用）：

| 模型 | 成功率 | 总耗时 p50 | 总耗时 p90 |
| --- | --- | --- | --- |
| DeepSeek-V4.1-Flash | 30/30 | 3.84s | 6.47s |
| MiniMax-M3.1-Flash | 30/30 | 3.05s | 4.38s |
| GLM-5.3-Flash | 30/30 | 4.87s | 8.10s |
| gpt-5.6-luna | 30/30 | 5.25s | 9.66s |

线上实测（普通请求，DeepSeek 主链）：**2.0～3.0s**；单次降级到 Luna 约 6s；双跳降级到 GLM 约 8.4s。

## 建议的 PPT 顺序

1. 背景：个人计划工具的使用门槛
2. 用户痛点：想不清楚、建议不落地、计划不敢改
3. 解决方案：一句话 → 提案 → 确认 → 可撤销
4. 系统架构：前端 / Node / Python / 模型 / MySQL
5. AI Agent 工作流程：ASR → 分层路由 → 结构化提案 → 确认落库
6. 核心功能：语音输入、方案卡、记忆、快照
7. Demo：现场演示或录屏
8. 技术实现：提案确认分离、降级链、熔断、revision 冲突控制
9. 实验与数据：模型对比表、延迟指标、成功率
10. 总结与展望：多端、主动提醒、更多场景
