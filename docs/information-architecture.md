# 信息架构

桌面主导航：今日、任务、项目、记录。设置置于侧栏下方；顶部只有搜索与快速记录。手机底部为今日、任务、快速记录、项目、记录。

主要地址：#/today、#/tasks、#/projects、#/projects/:key、#/records、#/settings。旧地址仍可访问兼容资料，普通导航不再展示学习、实验、时间轴和AI模块。

快速记录为弹窗：输入/录音、整理、摘要预览、展开单项修改、确认、显示保存清单。任务详情为抽屉，新增默认仅名称；项目新增只需名称和目标。阶段和里程碑降到更多选项。

保存结果明确列出类型、标题和去向，提供查看入口。删除任务和移出今日提供撤销，删除整个项目仍需确认。设置保留备份恢复、快照、提醒、旧工具与JSON导入。
