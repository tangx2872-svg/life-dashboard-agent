# 产品前端改造验收

日期：2026-10-29。对应实施前审计：[FRONTEND-AUDIT.md](FRONTEND-AUDIT.md)。

## 1. 原有问题

首页重复展示任务/路线/事项；导航不断追加；页面刷新丢失位置；任务缺少独立工作台；AI 解析结果与手动导入格式不同；输入错误也会锁住保存；移动端操作密度不统一。

## 2. 修改内容与页面结构

侧栏现在有 8 个入口：

|入口|内容|
|---|---|
|今日|1 个主要行动、最多 3 个次要行动、最近完成、最多 4 个进行中事项；子入口为本周回顾|
|任务|待办/进行中/已完成/全部；详情抽屉、子任务、日期时间、所属事项/阶段、优先级、标签、描述|
|事项|事项列表、下一步、任务、阶段、里程碑、全宽笔记|
|时间轴|未来/今天/过去；分组入口保留提醒与历史|
|学习与实验|原有学习路线、任务记录、实验及步骤|
|记录与想法|收件箱与 Ideas|
|AI Capture|自然语言/语音输入、结构化预览、编辑、确认；分组保留对话助手和高级 JSON 工具|
|数据管理|完整备份、恢复摘要、操作前快照、重复检查、原有管理工具|

使用 hash 路由保存页面和详情 ID；刷新、前进、后退有效。全局 Ctrl/Cmd+K 搜索任务、事项、笔记、想法；搜索显示最多 50 条并提示缩小范围。Quick Add 可直接创建任务、收件箱或事项笔记。

## 3. 展示层架构

- `product.css`：统一设计变量、布局、控件、抽屉、手机导航。
- `product-shell.js`：单一主导航、分组路由、命令搜索、快捷记录。
- `product-pages.js`：今日、事项和周回顾。
- `product-tasks.js`：任务行、表单、今日选择、完成恢复、删除确认。
- `product-ai.js`：解析状态、预览转换、编辑校验、确认保存。
- `product-api.js`：新 AI 工作流的同源请求与错误处理。
- 原业务文件继续负责路线/实验/备份/导入/进度计算等稳定规则。不是框架迁移，旧模块仍是原生 JavaScript。

## 4. API 与数据兼容

没有新增后端 API，也没有修改 AutoDL 内部实现。解析使用 `POST /api/ai/capture/text`，确认后使用原 `PUT /api/state` 的版本、CSRF、requestId 和 MySQL 事务。旧助手接口仍保留，未恢复直接 GPT 调用。

状态版本继续为 1；无清库或强制迁移。按操作追加：

- `todayFocus: {date, taskIds}`，最多 4 项。
- Task 的 description/status/priority/dueDate/time/createdAt/updatedAt/estimatedTime/tags/source/aiGenerated 等字段；`done` 仍为兼容的完成状态依据。
- 完成前的 `beforeCompletion` 保留子任务勾选，以便恢复。
- AI 来源记录保留原始解析时间 parsedStart/parsedEnd；实际显示和编辑使用 date/time，避免隐藏掉具体时刻。
- Event 追加 time/description。

完整备份自然包含以上字段及原有所有数据。旧备份无需新字段即可恢复。测试只使用随机 `life_dashboard_test_*` 数据库；没有添加测试数据到用户数据库。

## 5. 新增与合并

新增今日专注、任务工作台、完成恢复、抽屉、周回顾、命令搜索、移动导航、AI 编辑确认与加入今日。合并的是导航和重复首页展示，没有删除数据、路线、实验、提醒或手动导入能力。

## 6. 修复

- 刷新后回首页 → URL 保存所在页面。
- 无效表单使数据库进入断连状态 → 写入前校验失败可直接修改重试；真正网络写入不确定时仍要求重连。
- 完成后无法恢复 → 恢复任务及完成前子任务状态，移除该任务对应的完成历史。
- 删除任务残留今日引用 → 同步清理今日选择。
- 确认弹窗取消后快速重开出现重复节点 → 关闭节点清理和重复弹窗保护。
- AI 类型不匹配、重复批次、预览后状态变化 → 显式类型选择、批次拦截、版本检查。
- AI 具体时间无法在保存后看到 → 日程与任务支持时间及补充说明。

## 7. 测试结果

15 项自动化测试全部通过、0 跳过。包含：

- 真实 MySQL 事务、备份/恢复、版本冲突、请求幂等、异常输入。
- 原有项目/阶段/任务/子任务/笔记导入、顺序、删除关联、刷新、浏览器存储不可用。
- 助手 Mock 查询、预览、取消、修改、确认、范围限制、提醒。
- 新任务创建/完成/恢复、今日选择、路由刷新/前进/后退、搜索抽屉。
- AI Mock 预览不写库、编辑后确认保存、加入今日、重复批次、网络失败保留文字。
- 取消/确认删除、无效笔记输入可改正、250 条长任务。
- 1280×720、1440×900、1920×1080、390×844 下主要页面无横向溢出，手机导航可开关。

## 8. 尚待推进

1. 新 AI Capture 当前支持确认新增任务/日程/收件箱；自然语言修改、删除、长期规划仍需上游提供相应正式契约。高级 JSON v2 的增删改及旧助手测试能力继续保留，不能把 Mock 当成已上线智能能力。
2. 语音使用浏览器识别，支持程度/权限取决于浏览器；无支持时可输入文字。未新增后端音频上传。
3. 提醒仍是页面打开期间检查，关闭页面不会后台推送。
4. 旧路线、实验、数据管理等保留原业务页面并统一样式；部分高级操作仍使用原确认框，尚未全部拆成新组件。新 AI 请求已集中封装，旧存储/助手服务没有为了统一形式重写。
5. 全量状态 JSON 仍适合当前个人工具。更大规模数据的分页、细粒度 API、完整 ESLint 规则与 UI 模块格式化可后续分批进行。

以上限制不通过伪造结果或静默写入来掩盖。
